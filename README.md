# True — Educational Video Platform

True is an Arabic-first educational video platform being built as one continuous project across sequential implementation phases.

## Build order

1. Phase 00 — Foundation
2. Phase 01 — Courses
3. Phase 02 — Video Storage
4. Phase 03 — Commerce & Payments
5. Phase 04 — Entitlements, Device & Playback
6. Phase 05 — Dashboards & Admin
7. Phase 06 — Security, Testing & Integration

## Project rules

- This is ONE repository and ONE product.
- Each phase continues from the previous phase.
- Preserve working functionality from previous phases.
- Do not commit secrets or real credentials.
- Keep `PROJECT_CONTEXT.md` updated after every phase.
- Create/update `PHASE_REPORT.md` after every phase.
- Arabic-first, RTL, responsive and accessible.
- Payment is manual initially: Wallet and InstaPay.
- Video originals remain private; playback is protected.
- One active device per student account.
